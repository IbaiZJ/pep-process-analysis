# pep-process-analysis

An observational study of how the Python Enhancement Proposal (PEP) process
works in practice: who proposes changes, who decides, and how this has changed
over time. Based on the official process documentation and the Git history of
[python/peps](https://github.com/python/peps).

> Work in progress — Applied DevOps, Homework 1 (2026/27).
